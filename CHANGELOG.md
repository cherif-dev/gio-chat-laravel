# Changelog

All notable changes to `genit-io/chat-laravel` will be documented in this file.

## 1.0.0 - 2024-01-01

### Added
- Initial release
- One-to-one chat relationship between users and chats
- UUID-based chat IDs
- Chat message management with roles (user, assistant, system)
- Read receipt tracking
- Metadata support for chats and messages
- ChatService for managing all chat operations
- HasChat trait for User model integration
- Comprehensive documentation
- Automatic migrations
- Configurable user model
